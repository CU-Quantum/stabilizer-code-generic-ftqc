# Workspace Guidelines

## Python Environment
Always use the virtual environment located in the root directory of this project (`.venv`).
- When running Python scripts or commands, use `.venv/bin/python` or activate `.venv` (`source .venv/bin/activate`).
- When running tests, use `.venv/bin/pytest`.
- When running tools/executables, use the binaries located in `.venv/bin/` (e.g. `sinter`, `stim`, `pip`).
